# Doikayt Funding — Operating Mode

This repo tracks Doikayt's funding search across two peer tracks:

- [`fiscal-sponsorship/`](fiscal-sponsorship/) — identifying and pursuing a fiscal sponsor.
  See [`fiscal-sponsorship/CLAUDE.md`](fiscal-sponsorship/CLAUDE.md) for that track's operating
  mode.
- [`grants/`](grants/) — grant search. Not yet started; see
  [`grants/README.md`](grants/README.md).

Shared across both tracks:

- [`doikayt.profile.txt`](doikayt.profile.txt) — the org profile that drives screening and
  mission-alignment work in both tracks. Keep it current in one place rather than duplicating
  it per track.
- [`blurbs/`](blurbs/) — reusable descriptive text (mission, IP, product) drawn on by outreach
  and applications in either track.
- [`recruiting/`](recruiting/) — unrelated to funding; kept here as a peer directory rather than
  its own repo.

## Shared discipline

- Never guess — use `"Unclear"` / `"Requires confirmation"` when uncertain.
- Prefer primary sources over third-party descriptions; record source URLs on any claim.
- Flag legal/tax questions as needing counsel review rather than presenting them as settled.
- Commit after each meaningful update so history stays an audit trail.
